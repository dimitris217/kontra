# ΚΟΝΤΡΑ

Το παιχνίδι της κουβέντας. Υποθέσεις, κόντρες, ετυμηγορίες — σε ένα κινητό, για όλο το τραπέζι.

## Παιχνίδια
- **Κόντρα** (`index.html`): δικαστής, εισαγγελέας, υπεράσπιση, ένορκοι. Πόντοι & ζωές ή με ποινή, κρυφοί ρόλοι (Κόμπλεξ, Βύσμα), Διπλωματική ή Των πολιτών.
- **Κόντρα: Μπόνους!** (`kontra-bonus.html`): μετά από κάθε υπόθεση, μαντεύεις ποιος το είπε. Πρώτος στους 92.

## Δομή
```
index.html            Κόντρα
kontra-bonus.html     Κόντρα: Μπόνους! (bundled, όλα μέσα)
ops.js                όλες οι έτοιμες υποθέσεις
                        cats  = βάση της Κόντρας
                        bonus = φάκελοι του Μπόνους
manifest.json         PWA manifest
img/  fonts/          ζωγραφιές, ήχος, γραμματοσειρά (όλα τοπικά)
privacy-policy.html   πολιτική απορρήτου (για Google Play)
source/               πηγαίος κώδικας του Μπόνους (δεν χρειάζεται για να τρέξει)
```

Καθαρό HTML/CSS/JS. Χωρίς build, χωρίς εξαρτήσεις, χωρίς ιντερνετ.

## Τρέξιμο τοπικά
Άνοιξε το `index.html` σε browser. Ή, για να δουλεύουν σωστά όλα:
```
npx serve .
```

## GitHub Pages
Settings → Pages → Branch `main`, φάκελος `/ (root)` → Save.
Σε ~1 λεπτό: `https://<username>.github.io/<repo>/`
Πολιτική απορρήτου: `https://<username>.github.io/<repo>/privacy-policy.html`

## Android (Capacitor)
Αντέγραψε όλα εκτός από `source/`, `README.md` και `.gitignore` στο `webDir` (συνήθως `www/`) του Capacitor project και τρέξε:
```
npx cap sync android
```

## Αλλαγές
- Νέες υποθέσεις: `ops.js` → `cats`
- Νέος φάκελος Μπόνους: `ops.js` → `bonus`
- Ζωές / νίκες / 6 από 10: `index.html` → `CFG`
- Κανόνες: `index.html` → `V.rules`

## Σημείωση
Οι φράσεις του Μπόνους είναι πράγματα που κάποτε ειπώθηκαν δημόσια και δεν αντιπροσωπεύουν απαραίτητα τι πιστεύουν τα πρόσωπα. Αν βρεις λάθος απόδοση, άνοιξε ένα issue.
