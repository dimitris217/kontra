# ΚΟΝΤΡΑ — Web / PC

Η Κόντρα για υπολογιστή. Ανοίγει σε οποιονδήποτε browser, χωρίς εγκατάσταση.

- `index.html`: Κόντρα (παράθυρο στη μέση της οθόνης, hover, Enter = συνέχεια, Esc = πίσω)
- `ops.js`, `img/`, `fonts/`: υποθέσεις, ζωγραφιές, γραμματοσειρά

## Online δωρεάν
- GitHub Pages: ανέβασε τα περιεχόμενα σε repo → Settings → Pages → `main` / root.
- Netlify Drop: σύρε τον φάκελο στο https://app.netlify.com/drop

Τοπικά: `npx serve .` ή απλά άνοιγμα του `index.html`.
